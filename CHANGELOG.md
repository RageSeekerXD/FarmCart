# Журнал змін FarmCart

## 2.0.0 - веб-інтерфейс

План релізу - `docs/plan-release-2.md`, докази - `docs/evidence/ui/`.

### Зміни HTTP-контракту (несумісні з 1.x)

- Назви товарів, одиниць продажу й господарств - об'єкти `{ "uk": "...", "en": "..." }` у каталозі, кошику,
  рядках замовлення, товарах фермера й доставках кур'єра (було: рядок українською).
- `category` і `unit` товару - коди з довідника `GET /api/reference` (`vegetables`, `kg`, `jar-0.5l`, ...);
  невідомий код відхиляється з `category_unknown` або `unit_unknown`. Товар має ще `unitCode`.
- `POST /api/farmers`: `farmName` - двомовний об'єкт; без назви однією з мов - `farm_name_required`.
- `POST /api/farmer/products`, `PATCH /api/farmer/products/{id}`: `name` - двомовний об'єкт (`name_required`).
- `GET /api/catalog`: параметр `q` шукає обома мовами, новий параметр `lang=uk|en` задає мову сортування назв,
  `category` приймає код; елемент каталогу має `photoUrl`.
- Сповіщення `GET /api/me/notifications` мають `id`, `kind`, `orderId`, `params`; поле `text` збережено.

### Нове в API

- `GET /api/reference` - довідники категорій та одиниць продажу двома мовами.
- `GET /api/farmers?lat&lon` - верифіковані ферми для мапи з відстанню й кількістю товарів у сезоні.
- `GET /api/farmer/profile` - господарство продавця та стан верифікації.
- `GET /api/orders/{id}/review` - відгук покупця на власне замовлення.
- `GET /api/admin/promocodes` - список промокодів.
- `GET /api/demo/accounts` - демонстраційні акаунти для входу одним натисканням (лише в демонстраційному режимі).
- Хаб SignalR `/hubs/notifications`: подія `notification` користувачу одразу після події замовлення;
  кур'єр отримує сповіщення `delivery.assigned` про нову доставку.
- OpenAPI `/openapi/v1.json` (лише Development); сервер віддає зібраний веб-клієнт `web/dist` статикою.
- Налаштування `FarmCart:FixedTime` (зафіксований час для наскрізних тестів, заборонено в Production)
  і `FarmCart:WebRoot`.

### Веб-клієнт (`web/`)

- React 19 + TypeScript + Vite, MUI, TanStack Query, react-i18next; українська й англійська мови.
- Покупець: вхід за телефоном, каталог із фільтрами, мапа ферм, кошик, оформлення, мої замовлення з трекером,
  відгук після вручення.
- Фермер: реєстрація господарства з точкою на мапі, товари, вхідні замовлення.
- Кур'єр: доставки й вручення за кодом. Адміністратор: верифікація, слоти, промокоди, журнал аудиту.
- Сповіщення в реальному часі з резервним опитуванням.

### Демонстраційні дані

- 12 ферм (2 у черзі верифікації), 50 товарів у 7 категоріях обома мовами, 5 слотів доставки.
- Покупець `+380931112233` має по одному замовленню в кожному статусі; п'ять ферм мають відгуки.

### Перевірки

- `ci.cmd`: до кроків .NET додано eslint, перевірку типів, компонентні тести з покриттям, збірку клієнта
  й наскрізні тести Playwright.

### Відоме й невиконане

- Фото товарів немає: картки показують іконку категорії, `docs/attributions.md` не створено.
- Тексти помилок API, подробиці журналу аудиту й поле `text` сповіщень лишаються українськими;
  клієнт перекладає помилки й сповіщення за кодами.
- Сховище в пам'яті: після перезапуску сервера лишаються тільки демонстраційні дані.
